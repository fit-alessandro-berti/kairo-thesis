\section{Conclusion and Future Work}
\label{sec:conclusion}

Kairo learns recurring states that describe case progress, resource activity, and conditions across cases. Changes in how often these states occur give analysts a way to locate and investigate changes in event logs. In the benchmark, this approach surfaced selected resource and timing changes, while the strongest comparison profile achieved a better overall balance between precision and recall.

Future work should test fixed profiles on separate logs using only information available at the time of an alarm. It should also examine whether thresholds calibrated on stable periods and rules that suppress repeated alerts can reduce the effort needed to review alarms. A study with analysts could measure how the graphical interface helps them interpret changes.
